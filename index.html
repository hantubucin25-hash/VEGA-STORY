Konfigurasi Eksternal (store-config.json)

Simpan file store-config.json di folder yang sama dengan index.html di GitHub agar pembeli otomatis memuat setelan terbaru tanpa menyentuh index.html.

Alur Update di GitHub Tanpa Mengedit index.html:

1. Atur nama toko, metode pembayaran, & katalog di Panel Admin lalu klik Unduh store-config.json (atau edit langsung store-config.json di repository GitHub).

2. Unggah/commit store-config.json ke repository GitHub. Saat halaman dibuka, situs otomatis membaca ./store-config.json jika tersedia.
